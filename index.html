Winter Accountability Monitor

Monitoring: November 15, 2026 to April 15, 2027. We will update this page daily throughout the City’s winter services period.

257 of 268 cold nights

At least one person or couple was still left without a place at 4 a.m. on these nights at or below −5 °C from 2020–21 to 2025–26. People turned away at the door are not counted.

No one should suffer cold injury because they could not get indoors. A safe, warm place must be available before harm starts, every night.

Why this matters: Cold does not have to take a body part to cause serious harm. It can injure fingers, toes, ears, noses, cheeks, and other exposed skin. It can cause pain or numbness, damage skin, tissue and nerves, and make cold hurt more in the future. These problems can last for months or never go away. More severe cold can make tissue die, cause someone to lose a body part, or kill. Warm, dry clothes help, but they do not make long cold exposure safe. Safety cannot depend on someone owning special winter gear or having a home where they can warm up. People need a warm place before damage starts. This work asks whether Toronto has a safe place available when and where someone needs it. Sources: CDC and Mayo Clinic.

  • More spaces in 2023–24 to 2025–26: On nights from 0 to −5 °C, at least one space that a person could go to directly was open on nine nights in ten. It was open about two nights in five during 2020–21 to 2022–23.
  • Still nearly full (2023–24 to 2025–26): Cold-weather beds and spaces were almost completely full on 64 of 137 nights at or below −5 °C. On those nights, fewer than 2 out of every 100 spaces were empty.

A research paper is being prepared. We welcome corrections, new public data, and explanations from the City and its service partners.

Help us protect people from the cold

Why someone needs a safe, warm place does not matter. Everyone deserves warmth, safety, and a second chance without preventable physical harm.

Protection from cold is not a reward for perfect behaviour. A person’s mental health, history, or circumstances do not make cold injury acceptable. Keeping someone warm does not cancel accountability for harm.

BonQuery can track what happens, publish the evidence, and push for better protection. We cannot provide direct cold-weather help yet. We have no sponsors, supplies, outreach team, or volunteers for that work. We want to build that response with people who care.

Before monitoring begins on November 15, we will:

  • ask people with lived experience and frontline workers to review the words, safety contacts, and reporting plan;
  • seek funding to pay lived-experience reviewers rather than asking people to share trauma or work for free; and
  • publish the important changes that reviewers ask us to make.

A reporting line is planned, but it is not open. We will not record or transcribe reports until we have a clear consent message, secure storage, human review, a deletion policy, and people able to respond. Until then, use the verified services under I need help now.

function getVal(rows, key) {
  const row = rows.find(r => r.key === key)
  return row ? row.ind : null
}

validationChecks = {
  const rows = latestRows
  const checks = []

  // Check 1: all expected keys present
  const expectedKeys = [
    "all_shelter","room_based","singles_sector","singles_shelter","allied_summ",
    "temp_summ","iso_summ","fam_total","fam_emerg","fam_trans_r","fam_hotel",
    "sng_hotel","singles_total","emerg_total","mix_emerg","men_emerg","wom_emerg",
    "yth_emerg","trans_total","mix_trans","fam_trans_b","men_trans","wom_trans",
    "yth_trans","allied_total","respites","dropin","temp_resp","hotels","iso"
  ]
  const presentKeys = new Set(rows.map(r => r.key))
  const missingKeys = expectedKeys.filter(k => !presentKeys.has(k))
  checks.push({
    name: "All expected rows present",
    pass: missingKeys.length === 0,
    detail: missingKeys.length > 0 ? `Missing: ${missingKeys.join(", ")}` : null
  })

  // Check 2: All Shelter Programs total = sum of components
  const allShelter = getVal(rows, "all_shelter")
  const compSum = ["fam_total","sng_hotel","singles_total","allied_total","temp_resp","hotels","iso"]
    .reduce((s, k) => s + (getVal(rows, k) ?? 0), 0)
  checks.push({
    name: "All Shelter Programs rollup matches components",
    pass: allShelter === compSum,
    detail: allShelter !== compSum
      ? `all_shelter.ind=${allShelter}, component sum=${compSum}, diff=${allShelter - compSum}`
      : null
  })

  // Check 3: Singles sectors total = emergency + transitional
  const singlesTotal = getVal(rows, "singles_total")
  const emergTotal = getVal(rows, "emerg_total")
  const transTotal = getVal(rows, "trans_total")
  checks.push({
    name: "Singles sectors rollup: emergency + transitional = singles total",
    pass: singlesTotal === (emergTotal + transTotal),
    detail: singlesTotal !== (emergTotal + transTotal)
      ? `singles=${singlesTotal}, emerg+trans=${emergTotal + transTotal}`
      : null
  })

  // Check 4: For every row with non-null cap, occ + unocc = cap (within 1, for rounding)
  const capRows = rows.filter(r => r.cap !== null && r.cap > 0)
  const arithFails = capRows.filter(r => Math.abs(r.occ + r.unocc - r.cap) > 0.5)
  checks.push({
    name: "Internal arithmetic: occupied + unoccupied = actual capacity",
    pass: arithFails.length === 0,
    detail: arithFails.length > 0
      ? arithFails.map(r => `${r.key}: ${r.occ}+${r.unocc}≠${r.cap}`).join("; ")
      : null
  })

  return checks
}

function n(v) { return v !== null && v !== undefined ? v.toLocaleString() : "—" }
function pct(v) { return v !== null && v !== undefined ? v.toFixed(1) + "%" : "—" }

function offlineCell(r) {
  if (r.cap === null || r.cap === undefined) return `<td></td>`
  if (r.cap_funding === null || r.cap_funding === undefined) return `<td></td>`
  const offline = r.cap_funding - r.cap
  if (offline <= 0) {
    return `<td class="bq-num">${offline.toLocaleString()}</td>`
  }
  return `<td class="bq-num bq-danger">${offline.toLocaleString()}</td>`
}

function tableRow(r, col1Label) {
  const pad = (r.indent ?? 0) * 16
  const cls = r.is_total ? "bq-row-total" : "bq-row"
  const bld = r.is_total ? " bq-bold" : ""
  if (r.col_type === "summary") {
    return `<tr class="${cls}">
      <td style="padding-left:${pad}px" class="${bld}">${r.label}</td>
      <td class="bq-num${bld}">${n(r.ind)}</td>
      <td></td><td></td><td></td><td></td><td></td>

  }
  return `<tr class="${cls}">
