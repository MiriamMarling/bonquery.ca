Moniteur de responsabilité hivernale

Surveillance : du 15 novembre 2026 au 15 avril 2027. Nous mettrons cette page à jour chaque jour pendant toute la période des services hivernaux de la Ville.

  • Mieux récemment : Lors des nuits plus douces, de 0 à −5 °C, une place libre sans recommandation est passée d’environ deux nuits sur cinq à neuf nuits sur dix.
  • Toujours sous pression : Pendant la période actuelle, la couche activée était occupée à au moins 98 % lors de 64 des 137 nuits à −5 °C ou moins.
  • Bilan de six saisons : Au moins une personne seule ou un couple demeurait sans place lors de 257 des 268 nuits à −5 °C ou moins. Les refus à la porte ne sont pas comptés.

Un manuscrit est en préparation. Nous invitons la Ville et ses partenaires à nous transmettre des corrections, de nouvelles données publiques et du contexte opérationnel.

// La page Web de la Ville réutilise une seule ligne là où les données ouvertes

cityKeyAliases = ({
  singles_shelter_total: ["singles_shelter_total", "singles_shelter"],
  allied_total:          ["allied_total", "allied_summ"],
  iso:                   ["iso", "iso_summ"]

// The City sometimes prints a section total with only an individuals count and
// leaves the rest of the row blank, as it did for Allied Services on Aug 6.
// Where every component row is present, rebuild the missing columns from them.
// The identity holds exactly on every date the City published both, so this
// reproduces the City's own arithmetic rather than inventing a figure.
//
// Done here and not in the scrape on purpose: audit_city_scrape.py reads
// city_daily_table.json as evidence of what the City actually published, and
// a derived value written into that archive would show up in the daily audit
// as though the City had published it.
cityTotalComponents = ({ allied_total: ["respites", "dropin"] })

function cityDerivedTotals(rows) {
  const byKey = new Map(rows.map(r => [r.key, r]))
  const out = new Map()
  for (const [total, parts] of Object.entries(cityTotalComponents)) {
    const t = byKey.get(total)
    if (!t || t.city_occ !== null) continue          // already published in full
    const ps = parts.map(k => byKey.get(k))
    if (ps.some(p => !p || p.city_occ === null || p.city_unocc === null
                       || p.city_cap === null)) continue
    const sum = f => ps.reduce((a, p) => a + p[f], 0)
    const occ = sum("city_occ"), cap = sum("city_cap")
    out.set(total, {
      city_occ:   occ,
      city_unocc: sum("city_unocc"),
      city_cap:   cap,
      city_rate:  cap > 0 ? Math.round(1000 * occ / cap) / 10 : null
    })
  }
  return out
}

function cityRowsFor(date) {
  const rows = (city_table.entries ?? {})[date]
  if (!rows) return []
  const patch = cityDerivedTotals(rows)
  return rows.flatMap(row => {
    const keys = cityKeyAliases[row.key] ?? [row.key]
    return keys.map(key => {
      const t = rowTemplate.get(key)
      return {
        date,
        key,
        label:       t ? t.label : row.label,
        indent:      t ? t.indent : 0,
        is_total:    t ? t.is_total : false,
        col_type:    t ? t.col_type : row.col_type,
        ind:         row.city_ind,
        occ:         (patch.get(row.key) ?? row).city_occ,
        unocc:       (patch.get(row.key) ?? row).city_unocc,
        cap:         (patch.get(row.key) ?? row).city_cap,
        rate:        (patch.get(row.key) ?? row).city_rate,
        cap_funding: null,     // la page Web de la Ville ne la publie pas
        source:      "city"
      }
    })
  })
}

function offlineCell(r) {
  if (r.cap === null || r.cap === undefined) return `<td></td>`
  if (r.cap_funding === null || r.cap_funding === undefined) return `<td></td>`
  const offline = r.cap_funding - r.cap
  if (offline <= 0) {

  }

}

Le sous-total Tous les programmes de refuge et toutes les lignes de détail sont dérivés de l’exportation des données ouvertes CKAN. Les Programmes de passerelle et de triage sont suivis dans le système opérationnel de la Ville mais ne sont pas publiés dans les données ouvertes ; BonQuery collecte ce chiffre quotidiennement depuis la page du recensement des refuges de la Ville et l’affiche lorsqu’il est disponible. Le Total des personnes hébergées égale Tous les programmes de refuge + Passerelle et triage lorsque les deux sont disponibles. Certains chiffres de capacité et de lits inoccupés peuvent différer légèrement du tableau de bord en direct de la Ville en raison de différences dans la déclaration des lits hors service entre l’exportation CKAN et le système opérationnel de la Ville. Une comparaison côte à côte complète est disponible sur la page de validation des données.
