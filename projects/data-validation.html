Do the City’s Shelter Numbers Match?

We compare the City’s shelter webpage with its public data file

BonQuery checks whether Toronto’s shelter webpage matches the City’s public data file and shows the differences in simple terms.
Author

Miriam Marling

The City publishes daily shelter numbers in two places: a webpage and a public data file. Those numbers should match. We check them against each other.

// Known-difference keys (capacity/rate only — ind and occ match)
KNOWN_CAP_KEYS = new Set(["mix_emerg","men_emerg","wom_emerg","yth_emerg","emerg_total","singles_total"])

function mark(bqVal, cityVal, isCapOrRate, key) {
  if (cityVal === null || cityVal === undefined) return ""
  if (bqVal === null || bqVal === undefined) return ""
  const match = Math.abs(+bqVal - +cityVal) < 0.11
  if (match) return `<span style="color:var(--bq-success);font-weight:bold">✓</span>`
  if (isCapOrRate && KNOWN_CAP_KEYS.has(key))
    return `<span style="color:var(--bq-caution);font-weight:bold" title="Different number. See the explanation below.">*</span>`
  return ""
}

Why do some numbers differ?

The short answer is that the City does not explain how it makes every number on its webpage. BonQuery copies the City’s public data file. In the emergency-bed rows, that file and the City’s webpage show different numbers. We have asked the City to explain why.

The grey funded number is how many beds the City paid an operator to run. The City webpage does not show this number.

Every BonQuery number in this table comes from the City’s public data file. We show the two City sources together so people can see where they disagree.

What does “funded but unavailable” mean?

A funded but unavailable bed is a bed the City paid for that was not open to use that day. The City’s data lists reasons such as repairs, pest control, too few staff, or medical isolation.

The City does not show this count on its webpage. BonQuery calculates it like this: funded beds minus beds open to use. This matters most in dangerous weather, when every bed matters.

A program missing from the public data file

On May 14, the City webpage showed 29 people in Bridging & Triage Programs. The public data file did not include this program at all. That means the file alone cannot give the same total as the webpage. BonQuery has asked the City to add this program to its public file.

Does the City change old data?

We save a copy of the City’s file each time we update. A computer then checks whether the City changed any earlier row. If it did, BonQuery sends an email. The May 14 numbers have not changed since we first saved them on May 17, 2026.

What this means

The City publishes shelter numbers on a webpage and in a public data file. They often do not match. BonQuery shows the differences and saves the evidence so the checks can be repeated.
